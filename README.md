# Critical Crust

Помічник для кондитерів (як професіоналів, так і аматорів) з підбору рецептів
та замовлення інгредієнтів.

## Що робить система

- **Підбір рецептів** — на основі інгредієнтів, які вже є в користувача,
  система пропонує рецепти, які можна з них приготувати.
- **Замовлення інгредієнтів** — потрібні для рецепту інгредієнти можна
  одразу замовити зі складу.
- **Смакові характеристики** — кожен рецепт має опис смаку (солодкий,
  кислий, гіркий тощо) з рівнем інтенсивності, за яким рецепти можна
  фільтрувати.
- **Примітки про обладнання** — рецепт вказує, яке кухонне обладнання
  знадобиться (духовка, міксер тощо).
